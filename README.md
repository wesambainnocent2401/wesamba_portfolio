# Wesamba Innocent — Portfolio starter

## Project structure

- `index.html` — page content and semantic structure
- `css/style.css` — all styling and responsive layouts
- `js/script.js` — theme, navigation, services, gallery and contact behavior
- `assets/` — add your own images and resume here

## Add your files

Place these files in `assets/`:
- `profile.jpg` — your profile photo
- `design1.png` through `design6.png` — your portfolio designs
- `resume.pdf` — your resume

If you use different filenames, update the matching paths in `index.html` or `js/script.js`.

## Configure contact options

Open `js/script.js` and update the `CONFIG` object. Only publish contact or payment details that you are comfortable making public. For a young creator, a dedicated public-facing email or an adult-managed business contact is safer than publishing a personal number or payment account.

## Run locally

Open `index.html` in a browser. For a more realistic local development setup, use the Live Server extension in Visual Studio Code.

## Deploy

The project is static and can be deployed to Netlify or GitHub Pages. Upload the complete folder, keeping the `css`, `js`, and `assets` folders in their current locations.
